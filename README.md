# AIRena ROS2 Robot

A ROS2 + micro-ROS mobile robot built for the AIRena competition.

## Hardware

- ESP32
- L298N Motor Driver
- 2 DC Motors
- 3 IR Line Sensors
- HC-SR04 Ultrasonic Sensor
- SG90 Servo
- 2 × 3.7V Li-ion Batteries

## Software

- ROS2 Humble
- micro-ROS
- PlatformIO
- Gazebo
- RViz
